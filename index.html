Firebase Duplicator System

Read-only, one-way database copy & consolidation tool

Copies data from one Firebase Realtime Database into another over the REST API. Copy From is only ever read — never written to or deleted. Use it to back up a project before decommissioning it, or to fold several databases into one.

How this works
  1. Reads everything at Copy From with a plain HTTP GET. Nothing is ever written back to it.
  2. Preview the data or download it as a local .json backup before anything is written anywhere.
  3. Writes into Copy To as either Merge (PATCH — adds/updates top-level keys, leaves everything else at the destination alone) or Replace (PUT — completely overwrites whatever is at that path).
  4. If Copy From's rules don't allow public read, paste a database secret or ID token into its Advanced section.

Runs entirely in your browser — well suited to typical project-sized data. For very large databases, Firebase's own export tools are a better fit.
